# ניהול כספים

מערכת אישית לניהול כספים עם הכנסה לא קבועה, שמטרתה להגיע ליתרה יציבה של **₪5,000** ולשמור עליה.

המערכת לא רק מציגה נתונים — היא מתרגמת אותם להחלטות:
כמה בטוח להוציא עכשיו, האם רכישה מסוימת תדחה את היעד, ומתי לפי הקצב הנוכחי מגיעים ל-5,000.

> 🔒 **כל הנתונים נשמרים רק במכשיר שלך.** אין שרת, אין חשבון, אין קריאות רשת.
> קרא את [PRIVACY.md](PRIVACY.md) לפרטים מלאים — כולל המגבלות, בכנות.

## התקנה והרצה

```bash
npm install
```

```bash
npm run dev
```

### הרצה על הטלפון (מומלץ)

```bash
npm run build && npm run preview
```

`preview` מריץ עם `--host`, כך שתופיע כתובת רשת (למשל `http://192.168.1.20:4173`).
פתח אותה בטלפון **באותה רשת Wi-Fi** → תפריט הדפדפן → **"הוסף למסך הבית"**.

> ⚠️ **ההתקנה למסך הבית אינה אופציונלית ב-iPhone.** ספארי מוחק את נתוני האתר
> אחרי 7 ימים ללא שימוש — אלא אם האפליקציה מותקנת. אחרי ההתקנה היא עובדת אופליין.

## מבנה

```
src/
├─ core/     מנוע החישוב — TypeScript טהור. אין React, אין אחסון, אין רשת.
│            כל חישוב כספי גר כאן ורק כאן, ומכוסה ב-100% בדיקות.
├─ data/     סכמות Zod + Dexie/IndexedDB + גיבוי ושחזור.        (שלב 2)
├─ import/   ייבוא CSV/Excel, כפילויות, סיווג אוטומטי.          (שלב 3)
├─ ui/       מסכים ורכיבי React. אפס לוגיקה פיננסית.            (שלב 2)
├─ content/  קטגוריות וכללי סיווג ראשוניים.
├─ dev/seed/ נתוני דוגמה פיקטיביים — נטענים רק במצב פיתוח.
└─ tests/    בדיקות ו-fixtures.
```

### למה `core/` מבודד לחלוטין

כל מספר שמוצג במסך חייב להיות ניתן לבדיקה אוטומטית. פונקציה טהורה שמקבלת מערך עסקאות
ומחזירה תוצאה אפשר לבדוק בעשרות מקרי קצה תוך שניות; אותה לוגיקה בתוך קומפוננטת React — כמעט לא.

לכן `core/` הוא **חסר תלויות לגמרי** (אפילו לא ספריית תאריכים), כל פונקציה מקבלת את
`now` כפרמטר מפורש במקום לקרוא לשעון, וכל חישוב מחזיר גם אובייקט `breakdown`
שהממשק מציג כ"איך חישבנו את זה".

### החלטת AI לגרסה 1.0

בגרסה 1.0 אין AI בזמן ריצה. רשימת רעיונות ההכנסה נכתבה ונבדקה מראש,
והחישובים הפיננסיים דטרמיניסטיים. חיבור AI ישיר מהדפדפן היה חושף מפתח,
וחיבור בטוח היה מחייב שרת ושינוי של ארכיטקטורת ה־local-only. לכן האפשרות
נדחתה לגרסה עתידית; האפליקציה אינה שולחת נתונים ואינה דורשת מפתח API.

## חיבור לחשבון הבנק

אין, ולא יהיה בגרסה הזו.

חוק שירות מידע פיננסי (תשפ"ב-2021) מחייב **רישיון מרשות ניירות ערך** לקבלת גישה
אוטומטית לנתוני בנק, והספקים המורשים מגבילים את השירות לגיל 18+.
לכן: **אתה** מוריד דוח עסקאות מאתר הבנק, ומעלה אותו לאפליקציה. הקובץ מנותח בדפדפן ולא נשלח לשום מקום.

אין scraping, אין התחברות אוטומטית, ואין שום שדה לפרטי התחברות.
